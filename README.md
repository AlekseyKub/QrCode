# QrCode
Программа генерации QR кода

Реализует побайтовое кодирование.
----
Пример: QrCode.exe http://github.com github.svg h circle

1. перевым аргументом принимает данные для кодирования
2. вторым название файла для сохранения
3. трельим уровень коррекции (l m q или h)
4. четвертым стиль вывода (rect или circle, по умолчанию rect)
